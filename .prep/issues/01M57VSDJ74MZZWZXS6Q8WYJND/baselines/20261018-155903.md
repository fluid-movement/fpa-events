Source: review of the link-preview issue, 2026-10-18.

`stripHtml` in `src/lib/utils/html.ts` removes tags with a regex and nothing else. Event descriptions are stored as sanitized rich text, where `&` is `&amp;`, so the excerpt on the home page (`src/routes/+page.svelte`) and the link-preview description (`src/lib/utils/meta.ts`) show a literal `&amp;` (Svelte escapes it once more). A `<script>` or `<style>` block also leaves its inner text in the excerpt.

`stripHtml` should return plain text as a reader would see it: tags removed, the contents of script and style elements dropped, and the common entities decoded (`&amp;` `&lt;` `&gt;` `&quot;` `&#39;` `&nbsp;` and numeric `&#NN;` / `&#xNN;`), whitespace collapsed to single spaces. Its output is only ever rendered through Svelte (escaped) or an attribute, never as HTML, so decoding is safe; do not use it where the result is injected as HTML.
