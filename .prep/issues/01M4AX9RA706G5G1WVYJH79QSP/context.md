`safeRedirectPath(value, fallback)` in `src/lib/utils/urls.ts` admits only same-origin relative paths. `/sign-in` uses it for `callbackURL` (default `/dashboard`) and for the resend-verification callback; the sign-in ⇄ sign-up links carry `?redirect=`; `/sign-up` passes it as `callbackURL` so the verification link (autoSignInAfterVerification) lands there. Knowledge: /components/auth.md, /features/event-management.md.
