Reported by the owner 2026-11-01 on the event details form: typing 'hello' and saving stored 'h'; typing 'hello' again stored 'he'. Applies to every form using RichTextEditor (create event, edit event, schedule items).

Reproduced in a browser test: type 'hello world' into .ProseMirror on /events/create; the hidden description field still reads '<p></p>' and the saved row is '<p></p>'.

Cause: src/lib/components/RichTextEditor.svelte computes htmlContent as $derived(editor?.getHTML() ?? value). The only reactive input is the derived 'editor', and onTransaction replaces 'holder' with a new object that holds the same Editor instance, so 'editor' never changes and getHTML() is not re-run after the first change.

Fix direction: keep the HTML in a $state updated from the editor's onUpdate/onTransaction (html = editor.getHTML()), seeded with untrack(() => value), and spread field.as('hidden', html). Add an integration test that types into the editor, saves, and reads the stored description; the existing event-description test never touches the editor.
