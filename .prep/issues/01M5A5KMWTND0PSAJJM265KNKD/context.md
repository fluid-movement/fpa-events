Event form location input: `eventFormSchema` in `src/lib/server/eventForm.ts` validates latitude/longitude (finite plain decimals, lat -90..90, lng -180..180; blank allowed) and bounds city/country to 100 chars. `findOrCreateEventLocation` in `src/lib/server/db/eventLocations.ts` keys rows on city, country AND coordinates (within ~11 m), so the first writer cannot pin a city for later events and existing rows are never moved; no schema change. `EventsMap.svelte` plots only finite coordinates. Tests: unit in `eventForm.test.ts`, integration in `tests/integration/event-input-hardening.test.ts`. Prod event_locations cleanup check is for the owner.
