Unique index on `event_user (event_id, user_id)`; the generated migration first deletes duplicates, keeping an organizing row over attending, then the lowest id. `toggleRsvp` reads the user's row of any status, refuses organizers (400), and inserts with ON CONFLICT DO NOTHING so a double submit cannot race. `/invite/[token]` becomes an upsert to organizing. `tools/migrate` orders legacy rows organizing-first and inserts ON CONFLICT DO NOTHING, reporting how many duplicates it dropped. Seed already produces one row per (event, user). Production: run `npm run db:migrate` from the Coolify terminal.
