`handleError` in `src/hooks.server.ts` delegates to `describeServerError` (`src/lib/server/errors.ts`). Only `kind: 'unknown'` errors (real bugs) are logged and given an `errorId`; app/framework/validation errors keep Kit's defaults. The log line names the route id (`/invite/[token]`), never the raw path, because calendar-feed and invite URLs carry credentials. `App.Error.errorId` is optional; `+error.svelte` shows it as a reference. Source maps: the build already emits them; Node applies them with `NODE_OPTIONS=--enable-source-maps`, set in Coolify (manual). Knowledge: /architecture/build-and-deploy.md.
