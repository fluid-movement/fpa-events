users can create a "crew". a crew has members and a city homebase. there is a new crew listing with details links. on a crew details page all members of the crew can edit the following:
- a text that is translatable with a default language, a visitors browser langauge is used to decide which language is shown. cre members can add a language and translate the text (or just set a language for the text, and we have some browser api translate automatically?)
- a list of the locations events. so any event in that city is shown in that list
- a banner image

this will be a page that crews can set up in their own langauge, to help them spread the jam. they can write information about regular jams, etc in here, and if someone is interested they can point them here. so it is like a landing page for each communnity in a city
