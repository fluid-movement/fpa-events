`parsePictureFields` (`src/lib/server/eventForm.ts`) becomes the single gate: a changed picture must be under `R2_PUBLIC_URL/events/` (fresh uploads) and referenced by no other event, else 400. Legacy `/pictures/` URLs are only valid as the value an event already has. A new `releasePicture(url, eventId)` deletes from R2 only when no other event references the URL, used by update and delete. The upload endpoint allowlists jpeg/png/webp/gif/avif. Tests post the real edit form with another event's picture URL (postOverriding) and upload an SVG. Knowledge: /features/events.md.
