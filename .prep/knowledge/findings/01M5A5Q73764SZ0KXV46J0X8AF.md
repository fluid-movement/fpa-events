title: Postgres rejects NUL in text; real accepts NaN and Infinity
description: Any string containing a NUL byte that reaches a text column or comparison fails with 22021 and becomes a 500, so ids and form strings need checking before a query. Conversely, a real column silently stores NaN and Infinity passed from parseFloat (postgres-js sends them as text), so coordinates must be checked with Number.isFinite and a range before insert. Integer columns reject NaN (22P02) and values over 2^31 (22003). A JS Invalid Date makes Drizzle throw RangeError before the query. Checked on the dev DB with read-only casts, 2026-10-19.
