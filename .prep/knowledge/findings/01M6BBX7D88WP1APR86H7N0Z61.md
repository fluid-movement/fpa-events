title: A second dev server must not share .svelte-kit or the Vite cache with the first
description: 'The first version of the Turnstile test server (port 5175) shared .svelte-kit with the main test server (5174). Starting it rewrote the generated env files, including the Turnstile keys, and the 5174 server reloaded with them: the full suite went from 223/223 to 6 failures (settings and session specs, sign-ins failing). Giving 5175 its own outDir (SVELTEKIT_OUT_DIR=.svelte-kit-turnstile) and Vite cacheDir (VITE_CACHE_DIR) fixed it: 225 passed. The pre-change baseline was 223 passed. Failing specs passed when rerun alone, so the symptom looks like flakiness; check shared generated state first when a new server is added.'
